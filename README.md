# GameHub IPVG – Torneos de videojuegos y eSports

Plataforma web para organizar torneos internos de videojuegos y eSports del Instituto Profesional Virginio Gómez (sede Chillán).

**Tecnologías:** Vue 3 + Vite · Vue Router · NestJS · MySQL · TypeORM
